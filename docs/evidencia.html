Evidencia por caso

Petición, respuesta y resultado real de cada caso, capturados contra el servicio en producción.

Endpoints bajo prueba. GET https://api.thecatapi.com/v1/images/search y GET https://api.thecatapi.com/v1/breeds/search. Autenticación por encabezado x-api-key.

Como leer cada ficha. Petición es la URL exacta enviada. Autenticación indica si se envio la llave y por que canal. Respuesta trae el código de estado, el tiempo y el número de elementos. Encabezados recoge solo los relevantes para el caso. Cuerpo es la respuesta, recortada cuando es extensa. Resultado dice si el comportamiento fue correcto o que desviación se detecto.

Portal publicado automaticamente desde el repositorio en cada ejecución de la suite.
